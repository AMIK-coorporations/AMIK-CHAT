# پہلی بار لاگ ان

## اے ایم آئی کے چیٹ میں خوش آمدید!

یہ گائیڈ آپ کو پہلی بار لاگ ان کرنے اور اپنے اکاؤنٹ کو مکمل طور پر سیٹ اپ کرنے میں مدد کرے گی۔

## مرحلہ 1: اپنے ای میل کی تصدیق کریں

اکاؤنٹ بنانے کے بعد:

1. اپنے ای میل انباکس کو چیک کریں
2. اے ایم آئی کے چیٹ سے تصدیق کا ای میل تلاش کریں
3. "تصدیق کریں" بٹن پر کلک کریں
4. آپ خود کار طور پر لاگ ان ہو جائیں گے

> **نوٹ:** اگر آپ کو ای میل نہیں ملتا تو سپیم فولڈر چیک کریں۔

## مرحلہ 2: شروعاتی سیٹ اپ

پہلی بار لاگ ان کرنے پر آپ کو یہ معلومات فراہم کرنے کے لیے کہا جائے گا:

### ذاتی معلومات
- **نام**: آپ کا پورا نام درج کریں
- **پروفائل تصویر**: اختیاری - بعد میں بھی شامل کر سکتے ہیں
- **بائیو**: مختصر تعارف (اختیاری)

### پرائیویسی ترتیبات
آپ فیصلہ کریں کہ کون آپ کو دیکھ سکتا ہے:
- **سب**: کوئی بھی آپ کو تلاش کر سکتا ہے
- **صرف رابطے**: صرف آپ کی فہرست میں موجود لوگ

## مرحلہ 3: ہوم پیج کا جائزہ

لاگ ان کے بعد آپ کو یہ نظر آئے گا:

### اوپری بار
- **Logo**: اے ایم آئی کے چیٹ کا لوگو
- **تلاش**: پیغامات اور رابطوں میں تلاش
- **پروفائل**: اوپر دائیں کونے میں

### بائیں سائیڈبار  
- **چیٹس**: تمام گفتگو کی فہرست
- **رابطے**: آپ کی رابطہ فہرست
- **گروپس**: آپ کے جوائن کردہ گروپس
- **ترتیبات**: اکاؤنٹ کی ترتیبات

### مرکزی علاقہ
- **خوش آمدید پیغام**: شروعات کے لیے رہنمائی
- **شارٹکٹس**: اہم خصوصیات تک رسائی

## مرحلہ 4: اپنا پہلا رابطہ شامل کریں

1. "+" بٹن پر کلک کریں
2. **رابطہ شامل کریں** منتخب کریں
3. یہ میں سے ایک طریقہ استعمال کریں:
   - AMIK ID سے تلاش کریں
   - ای میل ایڈریس داخل کریں  
   - کیو آر کوڈ اسکین کریں

## مرحلہ 5: اپنی پہلی چیٹ شروع کریں

1. رابطے پر کلک کریں
2. نیچے ٹیکسٹ باکس میں پیغام لکھیں
3. **داخل کریں** دبائیں یا **بھیجیں** بٹن پر کلک کریں

## شارٹکٹ کلیدیں

چیزوں کو تیز کرنے کے لیے:

- `کنٹرول + N`: نئی چیٹ
- `کنٹرول + F`: تلاش کریں
- `کنٹرول + K`: فوری تلاش
- `کنٹرول + ,`: ترتیبات کھولیں
