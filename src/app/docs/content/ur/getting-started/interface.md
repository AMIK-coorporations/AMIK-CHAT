# انٹرفیس کا جائزہ

## اے ایم آئی کے چیٹ کی اسکرین کو سمجھیں

یہ گائیڈ اے ایم آئی کے چیٹ کے مرکزی انٹرفیس کے ہر حصے کی تفصیل فراہم کرتی ہے۔

## مرکزی لے آؤٹ

اے ایم آئی کے چیٹ کے 3 بنیادی حصے ہیں:

### 1. سائیڈبار (بائیں طرف)

#### نیویگیشن مینو
- **چیٹس** 💬: تمام گفتگو کی فہرست
- **رابطے** 👥: رابطہ کی فہرست
- **میں** 👤: اپنی پروفائل

#### فوری رسائی
- **نیا پیغام**: + بٹن سے
- **تلاش**: 🔍 آئیکن سے
- **منی پروگرامز**: اوپر سے نیچے کھینچیں

### 2. چیٹ کی فہرست (درمیان)

ہر چیٹ میں یہ نظر آتا ہے:

```
┌─────────────────────────────┐
│ 👤 نام                      │
│    آخری پیغام...            │
│                    🕐 وقت   │
└─────────────────────────────┘
```

**مخصوص علامات:**
- 🔵 نیلا نقطہ = نیا پیغام
- ✓✓ دو ٹک = پیغام پڑھا گیا
- ✓ ایک ٹک = پیغام پہنچ گیا
- 🔇 میوٹ آئیکن = بے آواز چیٹ
- 📌 پن آئیکن = اوپر رکھی گئی چیٹ

### 3. چیٹ ونڈو (دائیں طرف)

#### ہیڈر بار
```
┌──────────────────────────────┐
│ ← [نام]           🔍 📞 📹 ⚙️│
└──────────────────────────────┘
```

- **←** واپس جائیں
- **🔍** تلاش کریں
- **📞** آواز کی کال
- **📹** ویڈیو کال  
- **⚙️** چیٹ کی ترتیبات

#### پیغام کا علاقہ
پیغامات کا بڑا حصہ جہاں تمام چیٹیں نظر آتی ہیں۔

**پیغام کی اقسام:**
- عام تحریر
- تصاویر اور ویڈیوز
- فائلیں اور دستاویزات
- آواز کے پیغامات
- مقام کی شیئرنگ

#### ان پٹ باکس (نیچے)
```
┌──────────────────────────────┐
│ 📎 😊 | پیغام لکھیں...  🎤│
└──────────────────────────────┘
```

- **📎** فائل منسلک کریں
- **😊** ایموجی چنیں
- **🎤** آواز ریکارڈ کریں

## اوپری نیویگیشن بار

```
┌──────────────────────────────────────┐
│ اے ایم آئی کے چیٹ    🔍 تلاش...      🔔 👤│
└──────────────────────────────────────┘
```

- **لوگو**: ہوم پیج پر جائیں
- **تلاش بار**: تمام چیٹس اور رابطوں میں تلاش
- **🔔 نوٹیفکیشن**: اطلاعات دیکھیں
- **👤 پروفائل**: اکاؤنٹ مینو

## رنگوں کی اسکیم

### لائٹ موڈ
- **پس منظر**: سفید/ہلکا گرے
- **تحریر**: گہرا گرے/سیاہ
- **ایکسنٹ**: نیلا (#007bff)

### ڈارک موڈ  
- **پس منظر**: گہرا سرمئی/سیاہ
- **تحریر**: سفید/ہلکا گرے
- **ایکسنٹ**: ہلکا نیلا

**ڈارک موڈ فعال کریں:**
- ترتیبات > ظاہری شکل > ڈارک موڈ

## موبائل انٹرفیس

موبائل پر تین ٹیبز ہیں:

1. **چیٹس**: تمام گفتگو
2. **رابطے**: لوگوں کی فہرست
3. **میں**: پروفائل اور ترتیبات

## جیسچرز (موبائل)

- **دائیں سے بائیں سوائپ**: سائیڈبار کھولیں
- **بائیں سے دائیں سوائپ**: واپس جائیں
- **اوپر سے نیچے**: منی پروگرامز
- **پیغام پر لمبا دبائیں**: مزید آپشنز

## کسٹمائزیشن

آپ یہ بدل سکتے ہیں:

✅ **تھیم** - لائٹ/ڈارک  
✅ **فونٹ سائز** - چھوٹا/درمیانہ/بڑا  
✅ **بیک گراؤنڈ** - پہلے سے موجود یا اپنی تصویر  
✅ **آواز** - نوٹیفکیشن کی آوازیں
