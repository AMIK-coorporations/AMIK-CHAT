# انکرپشن

آپ کے پیغامات **اینڈ-ٹو-اینڈ اینکرپٹڈ** ہیں

## کیا ہے E2E Encryption?

صرف **آپ** اور **وصول کنندہ** پیغام پڑھ سکتے ہیں

- اے ایم آئی کے نہیں پڑھ سکتا 
- کوئی ہیکر نہیں پڑھ سکتا   
- حکومت نہیں پڑھ سکتی 

## تما م چیٹس محفوظ

- تحریر پیغامات 
- تصاویر اور ویڈیوز 
- آواز کے پیغامات 
- فائلیں 
- کالز
