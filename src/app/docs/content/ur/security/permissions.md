# اجازتیں

ایپ کی اجازتیں مینج کریں

## ضروری اجازتیں

### کیمرہ
- ویڈیو کالز
- QR اسکین
- تصاویر بھیجنا

### مائیکروفون
- آواز کی کالز
- آواز کے پیغامات

### اسٹوریج
- فائلیں بھیجنا
- تصاویر save کرنا

## اختیاری

- **Location** - مقام شیئر کرنا
- **Contacts** - قریبی تلاش

## بدلیں

ڈیوائس Settings > Apps > AMIK CHAT > Permissions
