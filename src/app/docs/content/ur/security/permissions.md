# اجازتیں

ایپ کی اجازتیں مینج کریں

## ضروری اجازتیں

### کیمرہ
- ویڈیو کالز
- کیو آر اسکین
- تصاویر بھیجنا

### مائیکروفون
- آواز کی کالز
- آواز کے پیغامات

### اسٹوریج
- فائلیں بھیجنا
- تصاویر محفوظ کریں کرنا

## اختیاری

- **Location** - مقام شیئر کرنا
- **Contacts** - قریبی تلاش

## بدلیں

ڈیوائس Settings > Apps > اے ایم آئی کے چیٹ > Permissions
