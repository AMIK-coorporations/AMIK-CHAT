# کیو آر کوڈ بنائیں

## اپنا کیو آر کوڈ بنائیں اور شیئر کریں

دوسروں کو آسانی سے اپنا کیو آر کوڈ دکھائیں تاکہ وہ آپ کو شامل کر سکیں۔

## اپنا کیو آر دیکھیں

1. **میں** پر جائیں
2. 📱 **کیو آر آئیکن** پر کلک کریں
3. آپ کا منفرد کیو آر نظر آئے گا

## کیو آر شیئر کریں

### اسکرین دکھائیں

- دوسرے کو اپنی اسکرین دکھائیں
- وہ اسکین کریں

### کیو آر سیو کریں

1. 💾 **ڈاؤن لوڈ** پر کلک کریں
2. تصویر محفوظ ہو جائے گی
3. کہیں بھی شیئر کریں

### پرنٹ کریں

- کیو آر ڈاؤنلوڈ کریں
- پرنٹ کریں
- دکان/دفتر میں لگائیں

## کیو آر کسٹمائز کریں
