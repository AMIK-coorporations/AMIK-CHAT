# کیو آر کوڈ سسٹم (QR Code System)

AMIK CHAT میں کیو آر کوڈ ایک بہت ہی کارآمد خصوصیت ہے جس کی مدد سے آپ بغیر نمبر ٹائپ کیے کسی کو بھی اپنے رابطوں میں شامل کر سکتے ہیں۔

## اپنا کیو آر کوڈ دیکھنا
1. اپنی پروفائل (Me) پر جائیں۔
2. اپنے نام کے ساتھ دیے گئے چھوٹے QR آئی کن پر کلک کریں۔
3. آپ کا ذاتی کیو آر کوڈ ظاہر ہو جائے گا جسے آپ دوسروں کو دکھا سکتے ہیں۔

## کیو آر کوڈ اسکین کرنا
اگر آپ کسی کا کوڈ اسکین کرنا چاہتے ہیں:
1. ہوم اسکرین پر اوپر دیے گئے اسکینر بٹن پر کلک کریں (یا مینی پروگرامز سے اسکینر کھولیں)۔
2. اپنے موبائل کیمرے کو دوسرے صارف کے کیو آر کوڈ کے سامنے لائیں۔
3. ایپ خود بخود ان کی پروفائل پہچان لے گی اور آپ انہیں "ایڈ" کر سکیں گے۔

## کیو آر کوڈ شیئر کرنا
آپ اپنا کوڈ تصویر کی صورت میں محفوظ کر کے واٹس ایپ یا دیگر ایپس پر بھی بھیج سکتے ہیں تاکہ لوگ آپ کو AMIK CHAT پر ڈھونڈ سکیں۔

> [!IMPORTANT]
> اپنا کیو آر کوڈ صرف ان لوگوں کے ساتھ شیئر کریں جنہیں آپ جانتے ہیں، کیونکہ اس کے ذریعے کوئی بھی آپ کو میسج کر سکتا ہے۔
