# عام مسائل

عام خرابیوں کے حل

## لاگ ان نہیں ہو سکتا

1. **ای میل** اور **پاس ورڈ** چیک کریں
2. **Caps Lock** آف ہے
3. **انٹرنیٹ کنکشن** چیک کریں
4. ایپ **اپ ڈیٹ** کریں

## پیغامات نہیں آ رہے

1. **انٹرنیٹ** چیک کریں
2. **نوٹیفکیشنز** آن ہیں
3. ایپ **ریفریش** کریں
4. **لاگ آؤٹ** اور پھر **لاگ ان** کریں

## آواز یا ویڈیو نہیں آ رہی

1. **اجازات** دی ہیں
2. **مائیک/کیمرہ** کام کر رہا
3. **اپ ڈیٹ** کریں
