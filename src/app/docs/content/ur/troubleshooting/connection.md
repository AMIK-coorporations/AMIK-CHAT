# کنکشن کے مسائل

انٹرنیٹ کنکشن کی خرابیاں

## "کنکٹنگ..." دیکھ رہے ہیں

### قدم

1. **وائی فائی/Mobile Data** چیک کریں
2. **Flight Mode** آف کریں
3. **Router ریسٹارٹ** کریں
4. **ایپ ریسٹارٹ** کریں

## سست کنکشن

- بہتر **وائی فائی** سگنل تلاش کریں
- **موبائل ڈیٹا** پر سوئچ کریں
- **VPN بند** کریں (اگر آن ہے)

## سرور مسائل

اگر AMIK کے سرورز down ہیں:
- کچھ دیر انتظار کریں
- [حیثیت چیک کریں](https://status.amikchat.site)
