# مصنوعی ذہانت خصوصیات

## مصنوعی ذہانت سے طاقتور خصوصیات

اے ایم آئی کے چیٹ میں مصنوعی ذہانت کی مدد سے آپ کا تجربہ بہتر بنایا گیا ہے۔

## خودکار ترجمہ

### پیغامات کا ترجمہ

دوسری زبان میں پیغام موصول ہوا؟

1. پیغام پر **لمبا دبائیں**
2. "🌐 ترجمہ کریں" منتخب کریں
3. اپنی زبان میں ترجمہ دیکھیں

**سپورٹ شدہ زبانیں:**
- اردو ↔ انگریزی
- اردو ↔ عربی
- اردو ↔ چینی
- +40 مزید زبانیں

### خودکار ترجمہ

مخصوص رابطوں کے لیے:

1. رابطہ کھولیں
2. ⚙️ **ترتیبات**
3. "خودکار ترجمہ" **آن** کریں
4. زبان منتخب کریں

تمام پیغامات خودکار ترجمہ ہوں گے! ✨

## اسمارٹ جوابات

### فوری جوابات

 پیغام ملنے پر 3 تجویز کردہ جوابات:

```
"ہاں"  "ٹھیک ہے"  "شکریہ"
```

- ایک ٹیپ میں جواب دیں
- مصنوعی ذہانت آپ کے انداز سے سیکھتی ہے

### سیاق و سباق سے آگاہ

مصنوعی ذہانت پچھلی گفتگو سے سیکھتی ہے:
- متعلقہ جوابات تجویز کرتی ہے
- آپ کا وقت بچاتی ہے

## پیغام کی تجاویز

### ٹائپنگ کے دوران

جب آپ لکھ رہے ہوں:

- ✨ **لفظوں کی تکمیل**
- 📝 **جملے مکمل کریں**
- 🎯 **اصلاحات**

**مثال:**
```
آپ: "مجھے ابھی نکل..."
تجویز: "نکلنا پڑے گا"
```

`ٹیب` دبائیں قبول کرنے کے لیے

## اسمارٹ تلاش

### تصاویر میں تحریر (او سی آر)

تصاویر میں لفظ تلاش کریں:

1. 🔍 **تلاش** کھولیں
2. لفظ لکھیں
3. تصاویر میں بھی تلاش ہوگی!

### آواز سے تلاش

- 🎤 مائیک آئیکن پر کلک کریں
- بولیں کیا تلاش کرنا ہے
- نتائج ملیں گے

## خودکار تنظیم

### اہم پیغامات

مصنوعی ذہانت خودکار طور پر پہچانتی ہے:
- 🔴 **ضروری**
- ⭐ **اہم**
- 📅 **تقرریاں**

### کیٹیگریز

چیٹس خودکار categorize:
- کام
- ذاتی
- خاندان
- گروپس

## آواز سے تحریر

### بولیں - لکھیں

1. 🎤 **آئیکن** پر کلک کریں (تحریر باکس میں)
2. بولیں
3. خودکار تحریر بن جائے گا

**90+ زبانوں میں!**

### علامات شامل

بولتے وقت کہیں:
- "کاما" → ،
- "سوالیہ نشان" → ؟
- "نیا پیراگراف" → ↵

## اسپام فلٹر

### خودکار تحفظ

مصنوعی ذہانت نامعلوم پیغامات چیک کرتی ہے:
- 🚫 اسپام = خودکار فلٹر
- ⚠️ مشکوک = انتباہ دیتی ہے
- ✅ محفوظ = عام طور پر دکھائیں

### فلٹر شدہ دیکھیں

- ترتیبات > سیکیورٹی > **فلٹر شدہ پیغامات**

## خصوصیت کی ترتیبات

### مصنوعی ذہانت آن/آف کریں

ترتیبات > مصنوعی ذہانت خصوصیات:

| خصوصیت | آن/آف |
|---------|--------|
| خودکار ترجمہ | ✅ |  
| اسمارٹ جوابات | ✅ |
| پیغام تجاویز | ✅ |
| اسپام فلٹر | ✅ |
| او سی آر تلاش | ✅ |
| آواز سے تحریر | ✅ |

## ڈیٹا پرائیویسی

### آپ کا ڈیٹا محفوظ

- مصنوعی ذہانت **محلی طور پر** کام کرتی ہے
- پیغامات **اینکرپٹڈ** رہتے ہیں
- کوئی ڈیٹا **فروخت نہیں**

> **یقین دہانی**: آپ کی رازداری ہماری ترجیح ہے!
