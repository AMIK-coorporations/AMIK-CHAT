# پیغام رسانی (Messaging)

AMIK CHAT کا بنیادی مقصد آپ کو اپنے قریبی لوگوں سے جڑے رہنے میں مدد دینا ہے۔ پیغامات بھیجنا بہت آسان ہے۔

## ٹیکسٹ پیغامات بھیجنا
1. کسی بھی چیٹ کو کھولیں۔
2. نیچے دیے گئے ٹیکسٹ باکس میں اپنا پیغام لکھیں۔
3. نیلے رنگ کے "بھیجیں" بٹن پر کلک کریں۔

## پیغامات میں ترمیم کرنا
اگر آپ سے کوئی غلطی ہو جائے تو آپ اپنے پیغامات کو تبدیل کر سکتے ہیں:
1. اپنے بھیجے گئے پیغام پر تھوڑی دیر (Long Press) دبائے رکھیں۔
2. "ترمیم کریں" (Edit) کا آپشن منتخب کریں۔
3. پیغام کو درست کریں اور "اوکے" دبائیں۔

## پیغامات کو حذف کرنا
آپ اپنے پیغامات کو دونوں طرف سے ڈیلیٹ کر سکتے ہیں:
1. پیغام کو دبائے رکھیں۔
2. "حذف کریں" (Delete) پر کلک کریں۔
3. "سب کے لیے حذف کریں" یا "صرف میرے لیے" کا انتخاب کریں۔

> [!NOTE]
> حذف شدہ پیغام کی جگہ ایک نوٹ نظر آئے گا کہ یہ پیغام ڈیلیٹ کر دیا گیا ہے۔
