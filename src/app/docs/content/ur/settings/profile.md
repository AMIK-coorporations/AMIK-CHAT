# پروفائل ترتیبات

اپنی پروفائل کسٹمائز کریں

## پروفائل میں ترمیم

**میں** > **پروفائل میں ترمیم**

### تصویر

- تصویر پر کلک کریں
- نئی تصویر منتخب کریں
- Crop > Save

### نام

- نام پر کلک کریں
- نیا نام لکھیں
- Save

### بائیو

- اپنے بارے میں (160 حروف)

[پرائیویسی ترتیبات](/docs/ur/settings/privacy)
