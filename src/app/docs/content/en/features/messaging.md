# Messaging

Send messages, share media, and express yourself.

## Sending Messages

1. Open a chat
2. Type in the text box
3. Press **Enter** or click **Send**

## Message Features

### Formatting
- **Bold**: *text*
- _Italic_: _text_
- ~~Strikethrough~~: ~text~

### Edit & Delete
- **Edit**: Hover > 3 dots > Edit
- **Delete**: Hover > 3 dots > Delete

### Reply & Forward
- **Reply**: Hover > Reply arrow
- **Forward**: Select message > Forward
