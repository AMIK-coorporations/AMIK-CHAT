# 账户设置

几分钟内创建您的 AMIK CHAT 账户。

## 注册

1. 访问 [amikchat.site](https://amikchat.site)
2. 点击 **注册**
3. 输入您的信息:
   - 电子邮件地址
   - 密码 (8+ 字符)
   - 显示名称
4. 点击 **创建账户**

## 电子邮件验证

1. 检查您的电子邮件收件箱
2. 点击验证链接
3. 您的账户已准备好!
