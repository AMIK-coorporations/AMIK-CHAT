# 消息

发送消息、分享媒体、表达自己。

## 发送消息

1. 打开聊天
2. 在文本框中键入
3. 按 **Enter** 或点击 **发送**

## 消息功能

### 格式
- **粗体**: *文本*
- _斜体_: _文本_
- ~~删除线~~: ~文本~

### 编辑和删除
- **编辑**: 悬停 > 3点 > 编辑
- **删除**: 悬停 > 3点 > 删除

### 回复和转发
- **回复**: 悬停 > 回复箭头
- **转发**: 选择消息 > 转发

## 表情符号和贴纸

点击  打开表情符号选择器。
